# ChurnSense AI

An AI-powered **Customer Churn Prediction & Risk Analysis** application built during my AI & Machine Learning internship at **Kinetrexa Software Private Limited**.

ChurnSense AI provides an interactive interface for analyzing customer information and generating customer churn risk insights through a Machine Learning workflow.

## 🚀 Live Demo

https://churnsense-ai-fronte-lhec.bolt.host

## 📌 Project Overview

Customer churn occurs when a customer stops using a company's service.

This project focuses on transforming customer information and usage data into meaningful features and using Machine Learning to support churn prediction and risk analysis.

The overall workflow is:

**Customer Data → Data Preprocessing → Feature Engineering → Machine Learning → Churn Probability → Risk Analysis**

## ✨ Key Features

- Customer churn prediction interface
- Churn probability and risk-level presentation
- Customer information input workflow
- Interactive and responsive web interface
- Integration-ready frontend for a Machine Learning API
- Clear presentation of prediction results
- Modern UI built with React, TypeScript and Tailwind CSS

## 🧠 Machine Learning Workflow

The project involved:

- Data cleaning and preparation
- Duplicate customer handling
- Missing-value treatment
- Customer-level feature engineering
- Monthly usage aggregation
- Customer tenure calculation
- Categorical feature encoding
- Train/test data preparation
- Logistic Regression
- Balanced Logistic Regression
- Random Forest Classification
- Churn probability and risk analysis
- Model evaluation using classification metrics

## ⚙️ Run Locally

### 1. Clone the repository

```bash
git clone https://github.com/virajaihub/churnsense-ai.git
cd churnsense-ai
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the development server

```bash
npm run dev
```

The application will be available at the local URL shown by Vite.
